[~] CHAT-003 — Dual LLM provider: re-add Claude API alongside Ollama
------------------------------------------------------------------------------
  Priority: HIGH
  Dependencies: CHAT-002

  DESCRIPTION:
  Re-introduce Claude API support using the Anthropic SDK while keeping the
  existing Ollama implementation intact. A new LLM_PROVIDER environment
  variable selects which backend to use at runtime ("claude" or "ollama",
  defaulting to "ollama" for backward compatibility). The Claude provider
  uses claude-haiku-4-5 with thinking disabled and prompt caching enabled
  (cache_control ephemeral on the system prompt). Both providers emit the
  same SSE wire format so the frontend ChatWidget requires no changes.

  TECHNICAL DETAILS:
  1. Dependencies (package.json):
    - Re-add @anthropic-ai/sdk

  2. API Route (src/pages/api/chat.ts):
    - Add import for Anthropic SDK at top of file
    - Replace Ollama Configuration block with unified Provider Configuration:
        LLM_PROVIDER = process.env.LLM_PROVIDER || 'ollama'
        OLLAMA_BASE_URL, OLLAMA_MODEL (unchanged)
        ANTHROPIC_API_KEY = process.env.ANTHROPIC_API_KEY || ''
        CLAUDE_MODEL = 'claude-haiku-4-5', CLAUDE_MAX_TOKENS = 4096
    - Add API key validation (503) when provider is claude and key missing
    - Extract existing Ollama streaming code into streamOllama(messages)
    - Add streamClaude(messages) using Anthropic SDK:
        client.messages.stream() with thinking: { type: 'disabled' },
        system prompt with cache_control: { type: 'ephemeral' },
        SSE output in same data: {"text":"..."} format,
        cache metrics logging on stream 'message' event
    - Dispatch: if (LLM_PROVIDER === 'claude') streamClaude else streamOllama

  3. Dockerfile:
    - Add ENV LLM_PROVIDER=ollama
    - Add ENV ANTHROPIC_API_KEY=

  4. Docker Compose (docker-compose.yml):
    - Add LLM_PROVIDER: ${LLM_PROVIDER:-ollama} to website environment
    - Add ANTHROPIC_API_KEY: ${ANTHROPIC_API_KEY:-} to website environment

  Files involved:
    MODIFY:  src/pages/api/chat.ts
    MODIFY:  package.json
    MODIFY:  Dockerfile
    MODIFY:  docker-compose.yml

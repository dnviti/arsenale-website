[x] CHAT-001 — Documentation chatbot with Anthropic API
------------------------------------------------------------------------------
  Priority: HIGH
  Dependencies: None
  COMPLETED: Documentation chatbot with Anthropic Claude API: floating chat widget, SSE streaming API route with rate limiting, build-time doc fetching, Docker deployment

  DESCRIPTION:
  Implement a floating chatbot widget that answers user questions based
  exclusively on Arsenale project documentation. The bot uses the Anthropic
  Claude API with a system prompt containing the full documentation content
  from https://github.com/dnviti/arsenale/tree/main/docs. Uses Astro hybrid
  mode with Node adapter so the API key stays server-side in an API route.
  Rate limiting prevents abuse. The bot refuses any questions unrelated to
  Arsenale documentation. Deployed via Docker container on a self-managed VPS
  with ANTHROPIC_API_KEY passed as an environment variable.

  TECHNICAL DETAILS:
  1. Astro Configuration:
    - Switch to output: 'hybrid' in astro.config.mjs
    - Add @astrojs/node adapter (mode: 'standalone')
    - All existing pages remain statically prerendered (hybrid default)

  2. Documentation Ingestion (build-time):
    - Node script (scripts/fetch-docs.mjs) fetches 8 markdown files from
      GitHub raw URLs at build time
    - Outputs src/data/docs-bundle.json with all doc content
    - Added as prebuild/predev npm lifecycle scripts

  3. API Route (src/pages/api/chat.ts):
    - export const prerender = false (server-rendered)
    - POST endpoint proxying to Anthropic Messages API
    - IP-based rate limiting (20 req / 15 min, in-memory Map)
    - System prompt embeds full documentation, instructs Claude to only
      answer Arsenale-related questions
    - SSE streaming for real-time response delivery
    - Uses claude-sonnet-4-20250514 model
    - ANTHROPIC_API_KEY read from process.env (never sent to client)

  4. Chat Widget (src/components/ChatWidget.astro):
    - Floating button (bottom-right, bg-primary) with chat icon
    - Expandable panel (384x512px, full-screen on mobile)
    - Dark theme using existing Tailwind tokens (dark-surface, dark-border)
    - Vanilla JS (no framework) matching Header.astro pattern
    - SSE stream reader for real-time token display
    - Session-only conversation history (JS array, max 20 messages)
    - Error/rate-limit feedback messages

  5. Docker Deployment:
    - Update Dockerfile: multi-stage build, run Astro Node standalone
      server instead of nginx
    - ANTHROPIC_API_KEY passed via docker run -e or docker-compose
    - Container exposes port 4321 (or configurable via HOST/PORT env)

  Files involved:

[x] CHAT-002 — Replace Anthropic Claude with Ollama for chat backend
------------------------------------------------------------------------------
  Priority: HIGH
  Dependencies: CHAT-001
  COMPLETED: Replaced Anthropic Claude SDK with self-hosted Ollama via native fetch, created docker-compose.yml with ollama-web/init/website services, updated branding and Dockerfile ENV defaults

  DESCRIPTION:
  Replace the Anthropic Claude Haiku integration with a self-hosted Ollama
  instance running in a Docker container. The Ollama container does not
  expose ports to the host network — it is only reachable via Docker
  internal networking from the website container. The server-side API route
  continues to proxy LLM calls so the frontend remains unchanged. This
  eliminates the dependency on the Anthropic API key and external API costs,
  enabling fully self-hosted documentation chat.

  TECHNICAL DETAILS:
  1. API Route (src/pages/api/chat.ts):
    - Remove @anthropic-ai/sdk import, use native fetch to call Ollama
    - Use Ollama OpenAI-compatible endpoint: POST /v1/chat/completions
    - Environment variables: OLLAMA_BASE_URL (default http://ollama-web:11434),
      OLLAMA_MODEL (default qwen3.5:0.8b)
    - Remove ANTHROPIC_API_KEY validation, cache_control, cache token logging
    - Parse Ollama SSE stream (choices[0].delta.content) and re-emit in
      existing data: {"text":"..."} format so frontend needs no changes
    - Keep rate limiting, system prompt, message validation, SSE headers

  2. Dependencies (package.json):
    - Remove @anthropic-ai/sdk from dependencies
    - No new dependency needed (Node 22 native fetch)

  3. Docker Compose (docker-compose.yml):
    - ollama-web service: ollama/ollama image, ollama_models volume,
      healthcheck on :11434, NO ports exposed to host
    - ollama-init service: pulls qwen3.5:0.8b model on first start,
      depends_on ollama-web healthy, restart: "no"
    - website service: ghcr.io/dnviti/arsenale-website, port 8080:8080,
      OLLAMA_BASE_URL and OLLAMA_MODEL env vars, depends_on both
      ollama-web healthy and ollama-init completed
    - Shared bridge network for internal communication
    - Named volume ollama_models for model persistence

  4. Chat Widget (src/components/ChatWidget.astro):
    - Update "Powered by Claude" branding text (line 71)

  5. Dockerfile:
    - Add ENV OLLAMA_BASE_URL and OLLAMA_MODEL defaults

  Files involved:
    CREATE:  docker-compose.yml
    MODIFY:  src/pages/api/chat.ts
    MODIFY:  package.json

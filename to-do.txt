[ ] CHAT-001 — Documentation chatbot with Anthropic API
------------------------------------------------------------------------------
  Priority: HIGH
  Dependencies: None

  DESCRIPTION:
  Implement a floating chatbot widget that answers user questions based
  exclusively on Arsenale project documentation. The bot uses the Anthropic
  Claude API with a system prompt containing the full documentation content
  from https://github.com/dnviti/arsenale/tree/main/docs. Uses Astro hybrid
  mode with Node adapter so the API key stays server-side in an API route.
  Rate limiting prevents abuse. The bot refuses any questions unrelated to
  Arsenale documentation. Deployed via Docker container on a self-managed VPS
  with ANTHROPIC_API_KEY passed as an environment variable.

  TECHNICAL DETAILS:
  1. Astro Configuration:
    - Switch to output: 'hybrid' in astro.config.mjs
    - Add @astrojs/node adapter (mode: 'standalone')
    - All existing pages remain statically prerendered (hybrid default)

  2. Documentation Ingestion (build-time):
    - Node script (scripts/fetch-docs.mjs) fetches 8 markdown files from
      GitHub raw URLs at build time
    - Outputs src/data/docs-bundle.json with all doc content
    - Added as prebuild/predev npm lifecycle scripts

  3. API Route (src/pages/api/chat.ts):
    - export const prerender = false (server-rendered)
    - POST endpoint proxying to Anthropic Messages API
    - IP-based rate limiting (20 req / 15 min, in-memory Map)
    - System prompt embeds full documentation, instructs Claude to only
      answer Arsenale-related questions
    - SSE streaming for real-time response delivery
    - Uses claude-sonnet-4-20250514 model
    - ANTHROPIC_API_KEY read from process.env (never sent to client)

  4. Chat Widget (src/components/ChatWidget.astro):
    - Floating button (bottom-right, bg-primary) with chat icon
    - Expandable panel (384x512px, full-screen on mobile)
    - Dark theme using existing Tailwind tokens (dark-surface, dark-border)
    - Vanilla JS (no framework) matching Header.astro pattern
    - SSE stream reader for real-time token display
    - Session-only conversation history (JS array, max 20 messages)
    - Error/rate-limit feedback messages

  5. Docker Deployment:
    - Update Dockerfile: multi-stage build, run Astro Node standalone
      server instead of nginx
    - ANTHROPIC_API_KEY passed via docker run -e or docker-compose
    - Container exposes port 4321 (or configurable via HOST/PORT env)
